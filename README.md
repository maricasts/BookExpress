# ⚙️ Utlização

> Esse sistema foi criado através do Replit. Por isso é recomendado utilizá-lo lá após importar os arquivos.

### Passos:
1. Baixe os arquivos presentes no GitHub  
2. Configure seu ambiente de Banco de Dados  
3. Rode no terminal utilizando:

> [!TIP]
> Se você baixar os arquivos e colocar no Replit, mesmo com uma conta gratuita, terá o projeto funcionando por alguns dias, te permitindo fazer alterações de forma mais visual e rápida.


Para testes:
```
mvn test
```
Compilar:
```
mvn clean compile
```
ou
```
mvn clean compile exec:java
```
